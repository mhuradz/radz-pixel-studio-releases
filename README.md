# Radz Pixel Studio v1.0.0 🚀

> **The native Windows image editor crafted for speed, elegance, and precision.**

Welcome to the first official release of **Radz Pixel Studio**! Engineered for creators, designers, and digital artists, Radz Pixel Studio combines a refined dark aesthetic with high-performance native GPU rendering.

---

## ✨ Highlights & Key Features

* 🎨 **Aurora Design System**: Immersive dark canvas accented by coral, violet, and silk tones. Features an elegant centered startup screen and streamlined canvas presets (Digital, Social, Print).
* ⚡ **Blazing Fast Native Performance**: Built in Rust and accelerated by GPU rasterization (`wgpu`). Instant startup, smooth high-framerate panning/zooming, and minimal memory footprint.
* 🛠️ **Photoshop-Parity Creative Workflow**: Layer masks, non-destructive adjustment layers, advanced typographic text tool, vector path tools, blending modes, and full PSD file import/export.
* 📦 **Zero-Dependency One-Click Setup**: Comes pre-packaged with all required Microsoft Visual C++ runtime libraries (`msvcp140.dll`, `vcruntime140.dll`, `vcruntime140_1.dll`). No external prerequisites needed—just run the installer and start creating!
* 🔄 **Built-in Smart Update Engine**: Background update detector notifies you when a new version is available. Choose to **Update Now**, **Update on Restart**, or **Remind Later**—never interrupting your active creative sessions.
* 🔒 **Private & Secure**: Completely self-contained with no telemetry, zero embedded tokens or credentials, and offline-first reliability.
